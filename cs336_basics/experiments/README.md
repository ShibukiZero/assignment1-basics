# Experiment Scripts

This directory contains executable experiment code for Assignment 1.

Use this directory for:
- training entrypoints
- generation entrypoints
- sweep summarizers
- sweep configuration files under `sweep_configs/`

Directory split:
- `cs336_basics/experiments/`: training, generation, and summarization entrypoints
- `cs336_basics/experiments/sweep_configs/`: JSON sweep grids
- `artifacts/experiments/ch7/`: durable experiment logs, summarized outputs, and plotting scripts
